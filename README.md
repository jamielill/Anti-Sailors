# Anti Sailors
This project is a 2D shmup set in a dystopian future where sailing is banned, and the ocean is controlled by outlaws and corrupt police. 

It was created for 'COMP1774 Object-Oriented Programming for Games', a module part of my University Degree in Games Design and Development.
The Initial game was developed using OOP principles and features four enemy types: Pirates, Skeletons, Police and BlackBeard. All of which inherit from the EnemyManager Class.
2D sprites were created in MS Paint and feature restrictive pixel resolutions: projectiles 8x8, items 16x16, boats 32x32 and compass 64x64.

Going forward, the resolution of assets will be doubled to create more detail while maintaining the pixel art aesthetic.
